How the numbers are measured

Each native → SomaSpeed pair ran on the same node and GPUs, with a 7,080-second budget per run including setup. Steady-state throughput is total samples divided by the sum of the slowest-rank step times after five warmup updates.

Batches are tuned separately. GPU interconnects differ across model comparisons. These are throughput measurements; convergence and robot task success are not evaluated here.

DISTRIBUTED TRAINING

Make room.
Share the work.

PyTorch FSDP2 spreads model parameters, gradients, and optimizer state across GPUs. HSDP adds another axis: replicate a group of shards to balance memory and communication.

Choose the mesh and checkpointing for each model. Retaining frozen weights can avoid repeated gathers, trading memory for less communication.

02

FUSED DENSE OPTIMIZATION

Small operations.
One coordinated flow.

Shared tile tables batch dense work across parameter tensors into four Triton launches. The first two build squared-norm statistics. After a shard-axis reduction, the third derives one global clip factor and per-parameter update scalars.

The final launch rereads the original gradients and fuses normalization, clipping, and AdamW updates. Gradient buffers stay unchanged. Native AdamW groups, state, and schedules are preserved; replica gradients aren’t counted twice in the norm.

4 shared launchesTriton kernels
THE OPTIMIZER STEP

Tiles read original gradients, divide by microbatch accumulation × data-parallel ranks, and write squared-norm partials. The gradient buffers stay unchanged.

03

FROZEN-PREFIX ATTENTION · π0.5

Keep the context.
Train the action.

The vision-language prefix stays frozen while the action expert learns. A custom attention kernel reads prefix and action keys and values as separate streams, using tiled online softmax.

Backward still reads both streams for query gradients. Only the trainable action keys and values receive gradients. No concatenated K/V buffer or full attention-score matrix is materialized.

Action queries read prefix then action K/V streams, tile by tile, sharing one online-softmax accumulator. Prefix queries attend only to the prefix. Both token blocks are bidirectional.

Conceptual access map for valid tokens in intermediate layers; padding is masked and scores are not stored as this matrix. The final prefix layer supplies K/V only, skipping its query, attention output, and MLP.
✳

Less unused work, across the stack. GR00T’s feature-only language backbone skips unused logits. Checkpointing applies to eligible model regions; configurable accumulation and frozen-weight retention keep the runtime adaptable.
